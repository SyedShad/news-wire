- Operational Review with consistent unread counts and acknowledge actions; no automatic external operational dispatch.
- Independent content and graphics model, ordered skills and customization controls in both dashboards.
- Local Sign in with ChatGPT, stdio Codex app-server execution, runtime catalogs, durable jobs, interactive input across processes, cancellation, retries, manual revisions and preserved source snapshots.
- Protected bounded artifact projections, authenticated previews/downloads, checksums and legacy draft history.
- Schema 11 article backfill and hosted migration 0007, preserving histories and notification ledgers without backfill generation or alerts.
- Signed UTF-8 bridge requests, bounded projection estimation, bulk resource queries, batched notification writes and hosted projection completion compatibility.
- Final validated source distinguishes provider-capacity errors from authentication/RPC failures and uses stable transport ranks to avoid historical output reuploads when new articles arrive. Those final changes await immutable installation.
