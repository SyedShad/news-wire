# News Wire 0.6.0 implementation status

The simplified feed and generation workspace are deployed to the existing owner-protected hosted dashboard. The Mac is installed on 0.6.0 with schema 11, and its stored article history has been backfilled. Real local text and graphics generation passed. Hosted generation is not ready: the initial history synchronization still times out before command delivery. See the [deployment acceptance record](0.6.0-deployment-acceptance.md) for observed results and remaining work.

## Implemented

- Separate, first-fetch-ordered articles with relevance as their only editorial eligibility rule; old and undated fetched articles remain visible, including recovery scans.
- Operational Review with consistent operational unread counts and acknowledge actions; no automatic external operational dispatch.
- Independent content and graphics model, ordered skills, and customization controls in both dashboards.
- Local Sign in with ChatGPT, stdio Codex app-server execution, runtime catalogs, durable jobs, interactive input across processes, cancellation, retries, manual revisions, and preserved source snapshots.
- Protected and bounded artifact projections, authenticated previews/downloads, checksums, and legacy draft history.
- Schema 11 article backfill and hosted migration 0007, preserving histories and notification ledgers without backfill generation or alerts.
